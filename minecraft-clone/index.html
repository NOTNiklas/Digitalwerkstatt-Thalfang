⛏️ Blockwelt

Ein kleiner Minecraft-Klon — läuft komplett im Browser

  • W A S D Bewegen
  • Maus Umsehen
  • Leertaste Springen / Fliegen (aufwärts)
  • Shift Sprinten / Fliegen (abwärts)
  • Linksklick Block abbauen
  • Rechtsklick Block platzieren
  • 1–7 Block auswählen
  • F Flugmodus umschalten
  • ESC Pause

Läuft am besten in einem modernen Desktop-Browser (Chrome, Firefox, Edge).
